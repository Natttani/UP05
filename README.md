# Портал «Блеск»

Информационная система клининговой компании: заказ уборки квартир и офисов, просмотр заявок и отзывов, панель администратора.

## Описание

Портал позволяет пользователю зарегистрироваться, войти в систему, оформить заявку на уборку (адрес, телефон, дата, время, вид услуги, способ оплаты), отслеживать статус своих заявок и оставлять отзыв после выполнения услуги. Администратор видит все заявки, меняет их статус, указывает причину отмены и фильтрует список по статусу и виду услуги.

## Стек

- **Бэкенд:** PHP 8.x, ООП (классы в `backend/classes/`), PDO, сессии, `password_hash` / `password_verify`.
- **База данных:** SQLite (файл создаётся из `backend/database/dump.sql` при первом запуске).
- **Фронтенд:** HTML5, CSS3, JavaScript (локально, без CDN — приложение работает офлайн).

## Запуск

1. Установить PHP 8.x с расширением `pdo_sqlite`.
2. Из корня проекта выполнить: php -S localhost:8000

3. Открыть `http://localhost:8000/`.
4. База данных создаётся автоматически из `backend/database/dump.sql` при первом запросе (файл `backend/database/app.sqlite`).

## Возможности

### Пользователь
- Регистрация (уникальный логин, пароль, ФИО, телефон `8(XXX)XXX-XX-XX`, e-mail).
- Вход / выход.
- Создание заявки: адрес, телефон (по умолчанию из профиля), дата `ДД.ММ.ГГГГ`, время `ЧЧ:ММ`, вид услуги из списка или «Иная услуга» с обязательным описанием, способ оплаты.
- Просмотр своих заявок: вкладки «Все / Активные / Завершённые».
- Отзыв с оценкой — только после статуса «Выполнено».
- Видна причина отмены, если заявка отменена.

### Администратор
- Все заявки пользователей, фильтр по статусу и виду услуги, пагинация.
- Смена статуса: «Новая» → «В работе» → «Выполнено» или «Отменено».
- Причина отмены обязательна при статусе «Отменено».
- Всплывающие уведомления о действиях.

## Реализованные требования модулей

- **Модуль 1:** БД SQLite с внешними ключами и справочниками, регистрация, авторизация, создание заявок, отзывы, админ-панель (статусы, причина отмены, фильтры, пагинация).
- **Модуль 2:** главная страница со слайдером (4 изображения, автосмена каждые 3 с, кнопки «вперёд/назад»), адаптивный дизайн 390×844 / 768 / 1280, валидация форм, «Иная услуга» с обязательным описанием, фильтры и пагинация в админке.
- **Модуль 3:** вкладки «Все / Активные / Завершённые» на «Моих заявках», причина отмены обязательна и видна пользователю, телефон в форме заявки по умолчанию из профиля, анимации карточек заявок и смены статуса, микроанимации кнопок и полей, выезжающие уведомления. SQL-запросы вынесены из `frontend/` в классы `backend/classes/`.

## Безопасность

- Пароли хранятся только в виде `password_hash()`.
- Все SQL-запросы с пользовательскими данными — подготовленные (`prepare` / `execute`).
- Весь пользовательский вывод экранируется через `htmlspecialchars()`.
- Проверка прав — на бэкенде: неавторизованный не откроет заявки, обычный пользователь не попадёт в админ-панель.
- Внешние ключи SQLite включены (`PRAGMA foreign_keys = ON`).
