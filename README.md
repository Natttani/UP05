# Портал «Блеск»

Информационная система клининговой компании: заказ уборки квартир и офисов, просмотр заявок и отзывов, панель администратора.

## Описание

Портал позволяет пользователю зарегистрироваться, войти в систему, оформить заявку на уборку, отслеживать статус своих заявок и оставлять отзыв после выполнения услуги. Администратор видит все заявки, меняет их статус, указывает причину отмены и фильтрует список по статусу и виду услуги.

## Стек

- **Бэкенд:** PHP 8.x, ООП (классы в `backend/classes/`), PDO, сессии, `password_hash` / `password_verify`.
- **База данных:** SQLite.
- **Фронтенд:** HTML5, CSS3, JavaScript.

## Запуск

1. Установить PHP 8.x с расширением `pdo_sqlite`.
2. Из корня проекта выполнить: php -S localhost:8000

3. Открыть `http://localhost:8000/`.
4. База данных создаётся автоматически из `backend/database/dump.sql` при первом запросе.

## Возможности

### Пользователь
- Регистрация (уникальный логин, пароль, ФИО, телефон `8(XXX)XXX-XX-XX`, e-mail).
- Вход / выход.
- Создание заявки: адрес, телефон (по умолчанию из профиля), дата `ДД.ММ.ГГГГ`, время `ЧЧ:ММ`, вид услуги из списка или «Иная услуга» с обязательным описанием, способ оплаты.
- Просмотр своих заявок: вкладки «Все / Активные / Завершённые».
- Отзыв с оценкой — только после статуса «Выполнено».
- Видна причина отмены, если заявка отменена.

### Администратор
- Все заявки пользователей, фильтр по статусу и виду услуги, пагинация.
- Смена статуса: «Новая» → «В работе» → «Выполнено» или «Отменено».
- Причина отмены обязательна при статусе «Отменено».
- Всплывающие уведомления о действиях.
